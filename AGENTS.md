# rtok-net — instructions for agents

**What.** rtok rewritten in C# on .NET 10: one tool that cuts tokens for coding agents; every method is a plugin. Surfaces: `rtok hook <event>` (and the tiny `rtok-hook` client), `rtok mcp`, `rtok proxy`. Release is NativeAOT, Debug is JIT.

**Read first.** `plan/README.md` (decisions N1–N21, package map, solution layout), `research.md`, and the catalog sections your task links in `docs/port/catalog.md`. No unplanned work: only tasks in `plan/`.

**Workflow.** Follow the project-plan skill. Claim a task in its `task.md` (`status: in progress`, your `<provider> / <model>` in `agent`, a short execution plan). Work only in your own git worktree (your session's, or `.worktrees/<id>`), never in the main checkout. One task, one branch `<id>-<slug>` cut from local `main`. Finish: `dotnet build rtok.slnx -c Release -warnaserror`, `dotnet test`, `dotnet csharpier check .` and `npx --yes markdownlint-cli2@0.23.3` green, write `plan/<id>/done.md`, commit `<id>: <title>`, rebase on `main`, then `git -C <main checkout> merge --ff-only <branch>`; if `main` moved, rebase and retry. `origin` is the public github.com/pyrlyn/rtok-net; agents never push or touch `origin`, only the human does. Your lane and its order are in `plan/README.md` (Parallel lanes).

**Rules.** No Rust code anywhere. NuGet first; missing pieces become own packages in `packages/` (`Pyrlyn.*` generic, `Rtok.*` rtok contracts). Fail open: the hook exits 0 within 10 ms, unmodified. Lossless: everything shortened comes back with `expand`. No Measurement row, no saving claim. Injections budgeted and byte-stable. Host configs: change only rtok's own entry, the rest byte for byte. No real agents in tests. One logic, one place. New dependency: one-line reason in the commit. Library code must stay AOT-clean (`IsAotCompatible`). The human is the only author: no `Co-Authored-By` or "Generated with" lines.
