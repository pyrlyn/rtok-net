# Agent hosts

`rtok agents install <host>` puts rtok into the coding agents on this machine and
`rtok agents uninstall <host>` takes it out again: only rtok's own entries change, every other
byte of a host's config stays. `rtok agents list` shows every host rtok knows, whether its apps
are here and what of rtok each one has; `rtok agents info <host>` shows one, `--json` the same as
JSON. `rtok agents update` rewrites rtok's entries in every host it is in.

Selection: `--cli` and `--desktop` (`--gui`) pick one app of a host that has both; `--all`, the
default, takes every app. `--dry-run` prints the edits and writes nothing. A file that does not
parse is refused, not rewritten. An entry you changed is left on uninstall unless `--yes`.

This build installs the MCP module. Hooks, proxy and plugin come with T35.3, T35.5 and T35.4;
the table already says where each will go.

## Support

`yes`: a plain install writes it. `` `--flag` ``: written only with that flag. `—`: the host
offers no way to write it. The last column names the rtok surfaces an app reaches through any
module.
