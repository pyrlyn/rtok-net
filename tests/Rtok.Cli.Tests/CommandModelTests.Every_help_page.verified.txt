$ rtok --help
Usage: [command] [-h|--help] [--version]

Commands:
  agents info         One or more hosts in detail: apps, files, and each module's state.
  agents install      Install rtok into hosts: its MCP server entry, keeping every other byte of their configs.
  agents list         Every host rtok knows: whether its apps are here, and what of rtok each one has.
  agents uninstall    Take rtok out of hosts: only entries that are still rtok's; one you changed asks first.
  agents update       Rewrite rtok's entries to what this rtok writes, in the hosts that have rtok (all of them when none is named).
  agents usage        Tokens and estimated cost per agent and month (or day), from the agents' logs or rtok.
     Prices come from [stats.prices]; a model without one counts in the tokens and is left out
     of the cost (--unpriced names those).
  completions         Print or install shell completions (bash, zsh, fish, powershell; clink for Windows cmd).
  config get          Print the effective value of one key or table.
  config init         Write the reference config file (every key commented out at its default) and print its path.
  config path         Print the path of the user config file.
  config set          Set a key in the user config file, keeping its comments; the result is checked first.
  config show         Print every effective key and value; secrets are redacted.
  config validate     Check a config file: unknown keys, types and ranges, with file:line; exit 1 on any problem.
  docs fetch          Download a dependency's docs at its lockfile-pinned version and index them for docs_query.
     Cargo.lock crates come from docs.rs, packages.lock.json packages from nuget.org.
  filter              Filter stdin as the output of a command, without running it.
  hook                Run one hook event from stdin, or serve hooks as this home's resident.
  logs                Print the last lines of rtok's log, numbered 1 = newest, across the rotated files.
  logs export         Print the same lines as rtok logs without numbers or colour.
  logs watch          Show rtok logs, then follow the log until Ctrl-C: repainted on a terminal, appended when piped.
  man                 Print the man page (roff), or write every page with --dir.
  plugins             List plugins: id, kind, enabled, surfaces.
  run                 Run a shell command, archive its output and print it filtered; exits with the command's code.

$ rtok agents usage --help
Usage: agents usage [options...] [-h|--help] [--version]

Tokens and estimated cost per agent and month (or day), from the agents' logs or rtok.
     Prices come from [stats.prices]; a model without one counts in the tokens and is left out
     of the cost (--unpriced names those).

Options:
  --source <string?>    Data source: logs (the agents' own session files, the default), rtok (what passed through rtok) or both. [Default: null]
  --host <string?>      Only these hosts, comma-separated (claude,codex). [Default: null]
  --since <string?>     From a date (2026-09-01, whole days in --tz) or a duration back from now (30d). [Default: null]
  --until <string?>     Through this date, inclusive. [Default: null]
  --daily               Bottom table by day.
  --monthly             Bottom table by month (the default).
  --by <string?>        Middle table grouping: agent (the default) or model. [Default: null]
  --tz <string?>        IANA time zone for day and month boundaries (default: the system zone). [Default: null]
  --unpriced            List the models without a price instead of the tables.
  --json                One JSON document.
  --config <string?>    The config file to use instead of ~/.rtok/config.toml. [Default: null]
