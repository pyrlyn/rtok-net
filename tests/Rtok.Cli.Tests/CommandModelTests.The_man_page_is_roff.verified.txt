.TH RTOK 1
.SH NAME
rtok
.SH SYNOPSIS
\fBrtok\fR [\fIoptions\fR]
.SH OPTIONS
.TP
\fB\-h\fR, \fB\-\-help\fR
Show help.
.TP
\fB\-\-version\fR
Show version.
.SH COMMANDS
.TP
\fBagents info\fR
One or more hosts in detail: apps, files, and each module's state.
See \fBrtok\-agents\-info\fR(1).
.TP
\fBagents install\fR
Install rtok into hosts: its hooks and MCP server entry, keeping every other byte of their configs.
See \fBrtok\-agents\-install\fR(1).
.TP
\fBagents junk clear\fR
Remove agent junk, each item checked again first: a dry run unless \-\-yes; exit 1 when some stays.
See \fBrtok\-agents\-junk\-clear\fR(1).
.TP
\fBagents junk list\fR
Per agent: its folders and sizes, the junk kinds in them, and what clear would free; read\-only.
See \fBrtok\-agents\-junk\-list\fR(1).
.TP
\fBagents list\fR
Every host rtok knows: whether its apps are here, and what of rtok each one has.
See \fBrtok\-agents\-list\fR(1).
.TP
\fBagents uninstall\fR
Take rtok out of hosts: only entries that are still rtok's; one you changed asks first.
See \fBrtok\-agents\-uninstall\fR(1).
.TP
\fBagents update\fR
Rewrite rtok's entries to what this rtok writes, in the hosts that have rtok (all of them when none is named).
See \fBrtok\-agents\-update\fR(1).
.TP
\fBagents usage\fR
Tokens and estimated cost per agent and month (or day), from the agents' logs or rtok.
See \fBrtok\-agents\-usage\fR(1).
.TP
\fBbatch fetch\fR
Write the results of a finished batch to a new file.
See \fBrtok\-batch\-fetch\fR(1).
.TP
\fBbatch status\fR
Print the provider's current state of a batch.
See \fBrtok\-batch\-status\fR(1).
.TP
\fBbatch submit\fR
Create a batch from a JSONL file of provider\-shaped requests; prints the batch object.
See \fBrtok\-batch\-submit\fR(1).
.TP
\fBbench\fR
Run each bench task with claude \-p under each [bench.configs] settings file and print mean tokens and cost per config.
See \fBrtok\-bench\fR(1).
.TP
\fBcompletions\fR
Print or install shell completions (bash, zsh, fish, powershell; clink for Windows cmd).
See \fBrtok\-completions\fR(1).
.TP
\fBconfig get\fR
Print the effective value of one key or table.
See \fBrtok\-config\-get\fR(1).
.TP
\fBconfig init\fR
Write the reference config file (every key commented out at its default) and print its path.
See \fBrtok\-config\-init\fR(1).
.TP
\fBconfig path\fR
Print the path of the user config file.
See \fBrtok\-config\-path\fR(1).
.TP
\fBconfig set\fR
Set a key in the user config file, keeping its comments; the result is checked first.
See \fBrtok\-config\-set\fR(1).
.TP
\fBconfig show\fR
Print every effective key and value; secrets are redacted.
See \fBrtok\-config\-show\fR(1).
.TP
\fBconfig validate\fR
Check a config file: unknown keys, types and ranges, with file:line; exit 1 on any problem.
See \fBrtok\-config\-validate\fR(1).
.TP
\fBdocs fetch\fR
Download a dependency's docs at its lockfile\-pinned version and index them for docs_query.
See \fBrtok\-docs\-fetch\fR(1).
.TP
\fBdoctor\fR
Check hooks, MCP servers, instructions and skills without running a hook; \-\-fix removes broken and extra copies.
See \fBrtok\-doctor\fR(1).
.TP
\fBexpand\fR
Print an archived original byte for byte, or the lines, grep hits or context you ask for.
See \fBrtok\-expand\fR(1).
.TP
\fBfilter\fR
Filter stdin as the output of a command, without running it.
See \fBrtok\-filter\fR(1).
.TP
\fBhook\fR
Run one hook event from stdin, or serve hooks as this home's resident.
See \fBrtok\-hook\fR(1).
.TP
\fBlogs\fR
Print the last lines of rtok's log, numbered 1 = newest, across the rotated files.
See \fBrtok\-logs\fR(1).
.TP
\fBlogs export\fR
Print the same lines as rtok logs without numbers or colour.
See \fBrtok\-logs\-export\fR(1).
.TP
\fBlogs watch\fR
Show rtok logs, then follow the log until Ctrl\-C: repainted on a terminal, appended when piped.
See \fBrtok\-logs\-watch\fR(1).
.TP
\fBman\fR
Print the man page (roff), or write every page with \-\-dir.
See \fBrtok\-man\fR(1).
.TP
\fBplugins\fR
List plugins: id, kind, enabled, surfaces.
See \fBrtok\-plugins\fR(1).
.TP
\fBproxy\fR
Run the API proxy in front of Anthropic, OpenAI and Gemini and record real token usage.
See \fBrtok\-proxy\fR(1).
.TP
\fBrun\fR
Run a shell command, archive its output and print it filtered; exits with the command's code.
See \fBrtok\-run\fR(1).
.TP
\fBstats\fR
Report tokens per tool, Bash family and MCP group from the agents' transcripts, with rtok's rows.
See \fBrtok\-stats\fR(1).
.TP
\fBtask claim\fR
Claim a task for this agent, or the first ready task when no id is given. On GitHub and GitLab the assignee write is last\-write\-wins.
See \fBrtok\-task\-claim\fR(1).
.TP
\fBtask conflict\fR
Record that two tasks touch the same files, so they should not run at once. Symmetric; ready flags a task whose partner is in progress.
See \fBrtok\-task\-conflict\fR(1).
.TP
\fBtask create\fR
Create a task under the next free id and print the id.
See \fBrtok\-task\-create\fR(1).
.TP
\fBtask dep\fR
Record that this task waits on another. A cycle is refused and nothing is written.
See \fBrtok\-task\-dep\fR(1).
.TP
\fBtask export\fR
Mirror the disk tasks one way into an issue tracker; the files stay the source of truth. A second run with nothing changed sends no write.
See \fBrtok\-task\-export\fR(1).
.TP
\fBtask init\fR
Write [tasks] into this checkout's .rtok.toml and seed the counter from existing tasks.
See \fBrtok\-task\-init\fR(1).
.TP
\fBtask list\fR
The plan: open and in\-progress tasks, subtasks under their parent.
See \fBrtok\-task\-list\fR(1).
.TP
\fBtask next\fR
The first ready task: free or stale, not blocked; a leaf when nothing is blocked.
See \fBrtok\-task\-next\fR(1).
.TP
\fBtask parallel\fR
Mark a task safe to run beside any other task.
See \fBrtok\-task\-parallel\fR(1).
.TP
\fBtask priority\fR
Set priority from 0 (highest) to 4. 2 is the default and is not stored.
See \fBrtok\-task\-priority\fR(1).
.TP
\fBtask ready\fR
Tasks that can be claimed, highest priority first.
See \fBrtok\-task\-ready\fR(1).
.TP
\fBtask release\fR
Clear the assignee and set the task open. Only the holder, unless \-\-force.
See \fBrtok\-task\-release\fR(1).
.TP
\fBtask show\fR
One task: title, status, parent, subtasks, link and description.
See \fBrtok\-task\-show\fR(1).
.TP
\fBtask status\fR
Print a task's status, or set it; done and closed move it out of the plan.
See \fBrtok\-task\-status\fR(1).
.TP
\fBtask sync\fR
Raise the id counters to the adapter's highest ids and report drift; never writes the adapter.
See \fBrtok\-task\-sync\fR(1).
.TP
\fBweb\fR
Serve the web dashboard until Ctrl\-C; prints its address with this run's token to stderr.
See \fBrtok\-web\fR(1).
.TP
\fBwrap\fR
Run a command with its API base URLs on the proxy, starting one when none answers.
See \fBrtok\-wrap\fR(1).
